# JINGS 製造業向けAI活用デモ

商談でそのまま見せられる、動くデモです。データはすべて架空企業「JINGSデモ精機」のもので、実在する顧客の情報は含まれていません。

## 使い方（営業メンバー向け）

社内限定です。Gitの知識は要りません。**3ステップ**です。

1. [**Releases から最新版をダウンロード**](https://github.com/JINGS-jp/jings-sales-demos/releases/latest) → `jings_demo.zip` をクリック
2. ダウンロードしたZIPをダブルクリックして展開
3. 中の **index.html** をダブルクリック

ブラウザが開けば準備完了です。ネットに繋がっていなくても動くので、商談先の通信環境を気にせず使えます。

> 会社のGitHubアカウントでログインしていれば、JINGS-jp のメンバー全員がダウンロードできます。
> アカウントを持っていない方は三上さんに連絡してください。

**よく使うなら**、展開したフォルダをデスクトップに置いて、`index.html` のエイリアスを作っておくと一発で開けます。

## 見せるときのコツ

- **「根拠」ボタンは必ず押す。** 出典が出せることが商談でいちばん効きます。押すと帳票の実物が出ます。
- **AIが勝手に確定しないことを見せる。** S・O・Dやリスクの点数は候補までで、決めるのは人という作りです。製造業ではここを言い切れるかどうかで話が変わります。
- **「確認できず」と「なし」を区別していることを見せる。** 文書が入っていないだけのものを、問題なしとして扱っていません。
- **Excel出力を押す。** 本物の.xlsxが出ます。「自社の様式に出せます」の裏付けになります。
- **帳票サンプル/** フォルダのExcelを画面と並べて開くと効きます（20ファイル）。

顧客のデータを使ったデモが必要なときは、三上さんに相談してください。

## 直したいとき（開発者向け）

```bash
python3 build.py     # src/ から docs/ を生成
python3 verify.py    # 9項目の回帰テスト
```

- `src/common/data.js` — 架空企業のデータ。全デモがここを共有しています
- `src/common/style.css` — 配色とUI部品。色は青・緑・橙・赤の4系統だけです
- `src/demos/*/` — デモごとの `meta.json`・`body.html`・`app.js`
- `docs/` — ビルド結果。1ファイルで完結するHTMLです

`sheets/gen_sheets.py` でExcel帳票を作り、`sheets/snap.py` でスクリーンショットを撮ってHTMLに埋め込んでいます。

配布用ZIPを作り直すときは次のとおりです。

```bash
cd docs && zip -qr /tmp/jings_demo.zip . && gh release upload latest /tmp/jings_demo.zip --clobber
```
