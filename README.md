# JINGS 営業デモ集

商談でそのまま見せられる、製造業向けAIデモです。データはすべて架空企業「JINGSデモ精機」のもので、実顧客の情報は入っていません。

## 使い方（営業メンバー向け）

Gitの知識は要りません。

1. このページ右上の緑の **Code** ボタン → **Download ZIP**
2. ダウンロードしたZIPを展開
3. `docs` フォルダの中の **index.html** をダブルクリック

ブラウザが開けば準備完了です。ネットに繋がっていなくても動きます。

`docs/帳票サンプル/` にExcelの帳票が20個入っています。画面と並べてExcelで開いて見せると効きます。

## 見せるときのコツ

- **「根拠」ボタンは必ず押す。** 出典が出せることが商談でいちばん効きます。押すと帳票の実物が出ます。
- **AIが勝手に確定しないことを見せる。** S・O・Dやリスクの点数は候補までで、決めるのは人という作りにしてあります。製造業ではここを言い切れるかどうかで話が変わります。
- **「確認できず」と「なし」を区別していることを見せる。** 文書が入っていないだけのものを、問題なしとして扱っていません。

## 直したいとき（開発者向け）

```bash
python3 build.py     # src/ から docs/ を生成
python3 verify.py    # 9項目の回帰テスト
```

- `src/common/data.js` — 架空企業のデータ。全デモがここを共有しています
- `src/common/style.css` — 配色とUI部品。色は青・緑・橙・赤の4系統だけです
- `src/demos/*/` — デモごとの `body.html` と `app.js`
- `docs/` — ビルド結果。1ファイルで完結するHTMLです

`sheets/gen_sheets.py` でExcel帳票を作り、`sheets/snap.py` でスクリーンショットを撮ってHTMLに埋め込んでいます。
